# Release Notes — 1.4.0

本版是自 `1.3.2` 以来的首个 **1.4 正式大版本**：双端（macOS / Windows，国服 / 国际服）全面升级至官方 **1.0.5** 客户端基底，推出全新的「官方账号 + 本机图鉴/Mod」**混合外观架构**、**面板右侧外延装备抽屉**，以及经过全面重组、职责更清晰的 **6 页签桌宠控制台**，并带来全局 `Alt+1～5` 快捷表情、背包批量合成、联机房间布局管理、省内存渲染调节与一系列实机稳定性修复。

## 一、同步官方 1.0.5 基底与原生能力

- **双区同步 1.0.5**：国服（`cn.json`）与国际服（`global.json`）规范锁、前端注入契约及 Windows 客户端基底同步更新至官方 **1.0.5**。
- **保留官方面板与系统原生特性**：完整保留官方 1.0.5 的自由缩放面板窗口（`.panel-resize-handle`）、全屏游戏避让模式与多显示器位置记忆，移除社区侧已由官方接管的冗余旧开关。
- **macOS 原生命令对齐**：补齐官方 1.0.5 新增的房间公开性、房主转让/移出成员、随机进房、重置应用、当前角色表情筛选、始终置顶、禁用指针监控与网络诊断等原生命令。

## 二、混合外观模式与面板右侧外挂装备栏

- **混合外观与官方账号并存**：默认启用本机全图鉴与 Mod 叠加层，不再替换官方面板页面或阻断联机房间；官方登录、余额计数、宝箱冷却、背包与联机写入均保持原版账号链路，叠加层初始化异常时自动安全回退官方 UI。
- **面板内来源选择与独立角标**：图鉴/背包内弹出「设为本地 / 设为官方」选择面板，官方已持有外观可同时挂「本地」与「官方」标签，仅本地或 Mod 外观严格限制仅本机使用并禁止提交至官方接口与统计埋点；预设按素材归属自动分流为云端预设（正 ID）与本地预设（负 ID）。
- **右侧外延扩张装备抽屉（不遮挡面板）**：在图鉴与背包页签最右侧挂载「本地 / 线上装备栏」，点击或拖出外观卡片时通过 Tauri 窗口外延向右拓宽面板外框，并保持官方面板本体宽度不变；支持本地（仅本机显示）与线上（联机可见）各自拖拽穿戴、表情拖拽排序及 `×` 一键卸下，收起或切换/关闭面板时自动收回窗口宽度。
- **自定义 Mod 支持**：支持在内存目录中叠加已导入的 Mod 资源包并在背包页前排展示与穿戴，卸载 Mod 后自动清理失效穿戴与角标；控制台支持导入 ZIP 与按包预览全部图标条目。

## 三、桌宠控制台重构与桌面效率工具

- **控制台重构为 6 个清晰页签**（兼容旧跳转入口）：
  - **概览 (`overview`)**：运行启停总控、点击速度/自动开箱/打字表情实时状态标签、核心点数统计、宝箱进度与最近奖励。
  - **自动助手 (`automation`)**：顶部实时搜索过滤，聚合「自动点击与余额策略」（含点击速度 1/5/10 档与点数下限暂停/上限恢复阈值）、「自动开箱」、「表情触发与快捷键」与「背包批量合成」。
  - **统计与记录 (`records`)**：合并展示最近 7 天计数趋势柱状图、本次发送/开箱清零与最近 1,000 条真实开箱获得记录。
  - **联机房间 (`rooms`)**：去过的房间收藏/一键加入/删除历史，以及本机视角的联机角色显示/隐藏、缩放比例、透明度、昵称大小、横向/纵向一键排列与位置重置。
  - **外观与 Mod (`mods`)**：挂饰水平/垂直偏移、缩放与 `-180°～180°` 角度微调（支持已保存配置加载编辑与删除）、Mod ZIP 导入与扫描、OBS 桌宠绿幕、面板背景图与透明度设置。
  - **系统与更新 (`system`)**：`30 FPS / 60 FPS / 跟随屏幕` 帧率上限与「空闲停帧 / 精简动画效果 / 停止渲染桌面主角」省内存渲染开关、整合版与官方基底版本检查、后台下载校验一键升级进度与更新说明、本机素材缓存同步。
- **全局 `Alt+1～5` 快捷表情**：无需聚焦桌宠或控制台窗口，在任意应用中按 `Alt+1～5` 即可触发对应槽位表情并自动短暂避让后台连点。
- **背包批量合成与合成日志**：按官方背包多余副本自动执行 5 合 1 同阶合成与 10 合 1 升阶合成（保留本体且跳过仅本地/Mod 条目），支持查看脱敏后的批次耗时与结果日志。

## 四、性能、稳定性与关键修复

- **Windows 全局热键与装备栏交互修复**：修复 Windows `rdev::Key` 键名（`Num1～5`、`Kp1～5`、`Alt`、`AltGr`）导致全局 `Alt+1～5` 无响应的问题；修复左键按下瞬间的 `localClickCount` 快照刷新重建装备槽位 DOM 导致点 `×` 失效的问题，并补充主窗口 `localSelection` IPC 同步。
- **渲染功耗与内存优化**：新增桌面主角与表情菜单 `requestAnimationFrame` 空闲停帧及帧率限制钩子，降低双端静置内存与 GPU/CPU 占用；macOS 优化 WebView 与本地资源内存开销。
- **更新与构建部署可靠性**：一键更新转为后台下载并持久化实时进度，支持失败退回 GitHub 手动下载；Windows 部署脚本在覆盖文件前清理残留宿主进程；移除遗留的辅助功能弹窗及失效旧开关。

## 五、下载与升级说明

- **已安装旧版（1.3.2 / 1.4.0-beta.*）**：进入控制台 **「系统与更新」 → 「检查更新」**，支持后台自动下载、校验并重启覆盖升级（保留账号、本地预设、Mod 资源包与设置）。
- **首次安装 / 手动升级**：根据地区与系统下载对应安装包并核对 `SHA256SUMS.txt`：
  - **Windows x64**：国服 `WuwaTappo-Full-CN-Community-Windows-x64-1.4.0.exe` / 国际服 `WuwaTappo-Full-Global-Community-Windows-x64-1.4.0.exe`。
  - **macOS (Apple Silicon, macOS 13+)**：国服 `WuwaTappo-Full-CN-Community-1.4.0-macOS-arm64.dmg` / 国际服 `WuwaTappo-Full-Global-Community-1.4.0-macOS-arm64.dmg`（因临时签名，首次安装或原地升级重启后若提示权限，请按引导在系统设置重新勾选一次「输入监控」）。
