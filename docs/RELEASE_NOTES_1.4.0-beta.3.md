# WuwaTappo Full Community 1.4.0-beta.3

## 1.4.0-beta.3 修复与增强

- **修复图鉴未持有卡片「设为本地」未生效**：点击未持有条目时按需自动开启本机叠加层，放行面板图鉴/背包/皮肤分支对本地选择的拦截，确保图鉴未持有与本地外观都能即时切换。
- **修复背包与图鉴「本地 / 官方」来源角标**：按槽位互斥清理旧角标，卸下配件或表情后同步移除对应角标，并在启动与状态同步时自动清理历史残留标记；通过事件与 storage 双通道跨窗口实时刷新。
- **修复挂饰位置 / 大小 / 角度调节**：支持官方挂饰与本地/Mod 挂饰同时调节，修复控制台与桌宠窗口跨 WebView 不同步的问题；控制台增加当前挂饰名称提示、数字微调输入框与焦点防回弹。
- **恢复 Mod 叠加渲染与一键穿戴**：将已导入并解析后的 Mod/本地目录在内存中增补进官方 `appearanceAssetCatalog` 与 `appearanceAtlasCatalog`（不篡改原始缓存），卸载 Mod 后自动清理已穿戴的失效条目与角标；控制台「Mod 管理」每个条目新增「设为本地」按钮。
- **官方接口与埋点防污染加固**：将 `reportHeartbeat`、云端预设创建/应用、`officialEmotes` 与 `select-appearance` 等官方路径剥离本地视觉状态替换；为 `reportSendSticker` 增加 `officialOwned` 守卫；主窗口「设为官方」增加 Mod/未持有条目硬拦截；收集进度分母排除 Mod/仅本地条目；官方已持有资产仍可正常同步收藏到账号。
