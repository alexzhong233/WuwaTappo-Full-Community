# Release Notes — 1.3.0-beta.1

第一个 beta。相对 1.3.0-alpha.3，这轮把控制台从「一个长页面」改成分页，Windows 补上了程序内一键更新，并跟进了上游 FullAtlas 1.3.4 / 1.3.7 的几项交互。**仍未做完整真机验收**，请当测试包用。

## 新增：控制台分页 + 独立的「更新」页

控制台不再把所有东西堆在一页，改成页签切换（Windows 控制台窗口的页签也一并整理了）。

「更新」页集中放四样东西：当前版本、官方基底版本、检查更新按钮、下载进度。检查完会直接显示**本次更新内容**——读的是 Release 说明；拿不到时退回解析发布页（GitHub 匿名接口按出口 IP 限 60 次/小时，打满时不会卡住页面）。

## 新增：Windows 程序内一键更新

更新页里点一下就把升级包下下来，带进度，装完自动重启。之前只能自己去 Release 页下载安装包。

同时加了两处顺手的事：

- 默认隐藏任务栏图标，只留托盘。
- 开机自启托管：在控制台里开关，不用自己去「启动」文件夹里翻快捷方式。

## 新增：桌宠右键菜单（Windows）/ 状态栏「控制台」入口（macOS）

- Windows 右键点桌宠弹出菜单，可以直接打开控制台、切换外观模式、退出。
- macOS 状态栏菜单加了「控制台」。
- 从托盘/状态栏点开控制台时，现在**先叫起面板再发指令**——之前会偶发「指令执行了但面板没出来」。

## 新增：跟上上游 FullAtlas 1.3.4 / 1.3.7

- **我的预设**：背包里「我的预设」的预览图按名字落到本机图，不再显示成 `？`。
- **打字自动表情**：输入时按上游的规则自动切表情。
- **分类收集进度**：图鉴里能看到按分类的收集进度。
- **403 处理**：裸 403 不再被当成凭证失效把人踢下线，只提示稍后重试。

## 修复

- 加载遮罩延迟 300ms 才显形，短请求不再闪一下白屏。
- 活动配置的后台刷新不再挂全屏遮罩（之前每次轮询都会闪）。
- 控制台底栏版本号统一用本仓库发布号。之前 macOS 显示 `1.3.0`、Windows 显示 `1.2`，看着像两个不同版本。
- Mod 表情改用本机取图地址。
- Windows 宿主进程随主程序退出，不再留后台残影。

## 内部改动（不影响用法）

这轮把「同一份代码抄两遍」的历史债清掉了，三个大件：

- 前端三件套（控制台、桌宠、图鉴控制器）改成单一源 + 生成器，两侧副本由脚本产出；谁手改副本，CI 直接拦。
- 注入器抽公共核，Windows / macOS 共用同一套补丁逻辑，只把平台差异做成钩子。
- 两个 cjs 工具合并成一个。

净减约 1600 行重复代码。重构前后用产物哈希逐字节比对过，注入结果与基线一致。

## 已知问题

- 表情受官方表情槽位数量上限约束，Mod 表情多了会被截断。
- 图鉴的稀有度筛选下拉里没有 `MOD` 项，按稀有度筛选时 Mod 条目会被过滤掉。
- 背包里 Mod 条目目前是按类型标签展示，不是独立分组网格。
- macOS 包仍是临时签名，重装后可能需要在系统设置里重新勾选一次「输入监控」。

## 安装

- **macOS**：Apple Silicon / macOS 13 及以上。先把 app 拖进「应用程序」再运行。
- **Windows**：下载 `.exe` 安装，装完双击快捷方式即可；已装旧版可以在控制台「更新」页一键升级。

## 试完请反馈

重点四条：更新页的版本号和「本次更新内容」对不对、Windows 一键更新能不能自己装完重启、右键菜单/状态栏入口能不能叫起面板、打字自动表情的触发时机是否跟手。有问题带上平台、服（国服/国际服）和面板上的报错文案。
