# WuwaTappo Full Community 1.4.0-beta.2

## 官方 1.0.5

- 国服、国际服同步到官方客户端 1.0.5，并更新 canonical lock、前端契约和 Windows 主程序指纹。
- 补齐官方房间公开、房主转让/移出成员、随机进房、重置应用、当前角色表情筛选、始终置顶、禁用指针监控和网络诊断等命令。
- 一键更新改为后台下载校验，控制台立即回到更新页并显示进度；失败时保留 GitHub 手动下载入口。

## 混合外观

- 默认启用本机全图鉴叠加，同时保留官方背包、联机和云端预设能力。
- 官方已有外观可标记为“官方”或“两者”，仅本地外观标记为“本地”。
- 新增“设为本地 / 设为官方”选择面板；全部素材均属于官方背包时创建云端预设，否则创建本地预设。
- 图鉴和背包显示来源角标；联机请求不再因本机外观被整体阻断。

## 桌面增强

- 挂饰支持水平、垂直、大小和 -180°～180° 角度微调。
- 自动检测鸣潮进程并切换官方游戏模式。
- 联机模式支持按官方背包重复数量批量同阶合成。
- 支持 Alt+1～5 快捷发送对应表情槽位。
- 控制台支持 OBS 绿幕/透明背景、面板背景图和透明度设置。

## 1.4.0-beta.2 修复

- 修复 macOS 桌宠和背包可能不显示：官方 UI 现在先无条件启动，本机图鉴/Mod 只作为后续叠加层启用。
- 本机叠加层初始化失败时自动回退官方 UI，不再替换整个应用页面。
- 删除控制台和官方设置页中全部“本地图鉴”开关。
- 删除联机页残留的“本地全图鉴已开启，无法进入联机”旧守卫，联机默认可用。
- macOS CN/Global 与 Windows PE 均重新注入验证。
