# Release Notes — 1.3.2-beta.1

本版把 Windows 本地服务与启动器整体换成 `shared/backend` 的 Rust 产物（与 macOS 共用同一份
领域代码），并修掉了迁移过程中丢掉的接口。两端仍基于官方国服 / 国际服 1.0.4。

## Windows 运行时迁移

- 本地服务 `LocalGalleryHost.exe` 与无控制台启动器 `WuwaTappoLauncher.exe` 由 Rust 编译，
  发行包不再包含 Python 运行时。安装目录少了约 20 MB 的解释器文件，冷启动更快。
- 补齐迁移时遗漏的四个接口：开机自启托管（`/startup`）、桌宠右键原生菜单
  （`/assistant/context-menu`）、面板上的「打开官方页面」两个入口。
- 应用内「一键更新」不再依赖旧版解释器目录，升级路径恢复正常。
- 启动器把本地服务的输出写到 `host.stdout.log` / `host.stderr.log`，服务起不来时有据可查。

## 修复

- 修复上一版 Windows 包无法构建的问题（启动器缺少导入、构建脚本把成功当失败返回）。
- 装配时清理旧版遗留的解释器目录，升级安装后目标目录不会长期保留无用文件。
- 诊断上报重新落盘到 `client_diagnostics.jsonl`，缺图时会逐条记录，便于定位素材缓存不完整。

## 验证

- `npm test`：194 项通过；新增的接口对账测试会把前端与注入器调用的本机接口逐个对照宿主路由，
  防止再次出现「前端在调、服务端没有」的静默失效。
- Rust 侧单元测试覆盖菜单校验、开机自启任务名与脚本转义、素材缓存与 Mod 校验。
- 真机验证：宿主启动后 `/status` 就绪、开机自启状态可读、右键菜单可弹出且不阻塞其他请求。

## 已知事项

- 右键菜单里点选菜单项后的动作回传、设置页开机自启开关的实际勾选，仍需人工点一遍确认。
- 预发布版本，业务功能仍以正式版为准。

## 基线

- 国服与国际服的官方客户端仍为 1.0.4，锁定的安装地址与摘要未变化。
