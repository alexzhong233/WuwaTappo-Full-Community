# Release Notes — 1.2.8

本版只修一个 macOS 授权问题，功能与 1.2.7 一致。

## macOS

**修复重装后「系统设置 > 隐私与安全性 > 输入监控」里找不到本应用。**

旧版只在检测到「未授权」时才发起授权请求。重装后，残留的旧授权记录仍让系统报告已授权，
应用于是从不重新请求，设置面板里那一行也就再没被重建——键鼠监听其实一直能用，列表里却没有本应用，
用户既看不到也撤不掉这条授权。

- 已授权时也会重新登记一次（系统不会再次弹窗，也不会改动现有授权），启动时静默补一次；
  主菜单「启用键鼠监听…」同样会补登记，可用来手动修复列表缺失。
- 启动日志新增一行权限状态（仅权限与路径，不含任何输入内容），可在菜单「打开日志目录」中查看：
  `Input access: input-monitoring=… hid=… accessibility=… translocated=… hint=…`
- 新增 `repair-input-permission.sh`：默认只输出诊断；加 `--reset` 才会清掉失效记录并重新授权。
- 打包支持 `APPLE_SIGNING_IDENTITY`，用固定开发者证书签名可让输入监控授权跨版本保留。
  **本次发布仍是临时签名**，重装或升级后可能需要在系统设置里重新勾选一次。

## 安装

- **macOS**：Apple Silicon / macOS 13 及以上。先把 app 拖进「应用程序」再运行——从 DMG 里直接双击，
  系统会把应用放到随机路径，输入监控授权绑在那条路径上，下次启动必然对不上。
- **Windows**：下载 `.exe` 安装后双击快捷方式即可使用。

## 已知问题

- 临时签名每次重装都可能要重新授权输入监控。这是签名问题，不是权限逻辑问题；固定证书签名的包不受影响。
