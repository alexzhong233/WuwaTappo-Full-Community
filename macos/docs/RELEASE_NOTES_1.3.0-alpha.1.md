# Release Notes — 1.3.0-alpha.1

预发布版，用于试「全图鉴 + Mod」。功能基于 1.2.8（官方 1.0.4 基底）叠加，**尚未做真机验收**，请当作测试包看待。

## 新增：自己导入角色、挂饰和表情

「挂机与统计」多了独立的 **Mod 管理** 页：

- 切换外观模式：官方模式只用账号背包；「全图鉴 + Mod」使用完整离线图鉴并叠加本机导入的资源。
- 导入 ZIP、重新扫描、逐个包移除；每个包展开条目缩略图，导入后能立刻确认图有没有配对。
- 包内不用填 ID，编号由包名和条目名推导：改图片、调顺序都不变号，改名才算新条目。

一个包可以只放一样东西，也可以混装：

| 类型 | 最少图片 | 能做什么 |
| --- | --- | --- |
| 角色 | 2 张（`body1` + `head1`） | 新增一个可选的桌宠外观 |
| 挂饰 | 1 张（`image`） | 新增一个配件 |
| 表情 | 1 张（`image`） | 新增一个表情 |

角色的动作帧是固定五格：`body1` 待机、`body2` 向左走、`body3` 向右走、`head1` 常规、`head2` 眨眼（每 5 秒约 0.25 秒）。给了就播，没给就用基础帧补齐——不会出现某层闪空。**目前没有独立的「动作」条目，也不能替换官方角色的帧**，动作只能随角色一起给。

## 新增：演示包

仓库里带了 `macos/docs/mod-examples/demo-animated-pet.zip`，直接导入即可试：静置看眨眼，拖动看迈步。五帧齐全，同目录有逐帧预览和制作说明。

## 新增：背包里的区分

- Mod 条目在背包缩略图上带紫色虚线描边 + `MOD` 角标。
- 按稀有度分组时 Mod 单独成组（组名 `MOD`）并排在最前；「全部」平铺列表里也排最前。
- **只在「全图鉴 + Mod」下生效**：切回官方模式，条目、角标、分组位置全部消失，账号背包不受影响。

## 修复

- 发行包不再夹带本机导入的 Mod（之前打包会把 `custom-atlas` 一起带走）。
- Mod 层不再是基础功能的前置条件：没装 Mod 时官方图鉴原样返回；叠加失败时退回官方图鉴并在 Mod 管理里显示原因，不会让整个本地图鉴打不开。
- Windows 的 Mod 单元测试已纳入 CI。

## 已知问题

- **macOS 上 Mod 图片暂时显示不出来**（本轮已知，未修）。官方解析图片地址的函数只放行 `http(s)://`，而 macOS 的本地图是 `asset://` 协议，会被拼成 CDN 地址后 404。Windows 走本机 HTTP，不受影响。要修需要给 macOS 加一条本机取图路由，属设计取舍，安排在下一轮。
- macOS 国际服仍未接入 FullAtlas 控制面板，Mod 界面只在 macOS 国服可用；Windows 国服/国际服共用同一入口。
- 表情受官方表情槽位数量上限约束；图鉴的稀有度筛选下拉里没有 `MOD` 选项，按稀有度筛选时 Mod 条目会被过滤掉。

## 安装

- **macOS**：Apple Silicon / macOS 13 及以上。先把 app 拖进「应用程序」再运行。本包仍是临时签名，重装后可能需要在系统设置里重新勾选一次输入监控。
- **Windows**：下载 `.exe` 安装后双击快捷方式即可使用。

## 试完请反馈

重点看三件事：导入后缩略图对不对、切换模式后背包有没有残留、眨眼和走动是否真的换帧。有问题带上 `custom-atlas/` 里的包名和面板上的报错文案。
