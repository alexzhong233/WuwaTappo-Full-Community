# Release Notes — 1.3.0

1.3.0 是「全图鉴 + Mod」转正的版本：自己导入的角色、挂饰、表情可以正式用了，控制台改成按页签组织，Windows 补上了程序内一键更新。官方基底跟到 **1.0.4**（国服 / 国际服同基底）。

从 1.2.8 升级的话，下面这些是新增的；只看本版改动的可以跳到「修复」。

## 全图鉴 + Mod

控制台多了独立的 **Mod 管理** 页，外观模式多出一个「全图鉴 + Mod」：

- 官方模式只用账号背包；「全图鉴 + Mod」使用完整离线图鉴并叠加本机导入的资源。
- 导入 ZIP、重新扫描、逐个包移除；每个包展开条目缩略图，导入后能立刻确认图有没有配对。
- 包内不用填 ID，编号由包名和条目名推导：改图片、调顺序都不变号，改名才算新条目。

一个包可以只放一样东西，也可以混装：

| 类型 | 最少图片 | 能做什么 |
| --- | --- | --- |
| 角色 | 2 张（`body1` + `head1`） | 新增一个可选的桌宠外观 |
| 挂饰 | 1 张（`image`） | 新增一个配件 |
| 表情 | 1 张（`image`） | 新增一个表情 |

角色的动作帧是固定五格：`body1` 待机、`body2` 向左走、`body3` 向右走、`head1` 常规、`head2` 眨眼。给了就播，没给就用基础帧补齐，不会出现某层闪空。

仓库里带了演示包 `macos/docs/mod-examples/demo-animated-pet.zip`，直接导入即可试：静置看眨眼，拖动看迈步。

Mod 条目在背包里带紫色虚线描边 + `MOD` 角标；切回官方模式后条目、角标、分组位置全部消失，账号背包不受影响。

## 控制台分页 + 独立的「更新」页

控制台不再把所有东西堆在一页，改成页签切换。

「更新」页集中放四样东西：当前版本、官方基底版本、检查更新按钮、下载进度。检查完会直接显示**本次更新内容**——读的是 Release 说明，拿不到时退回解析发布页（GitHub 匿名接口按出口 IP 限 60 次/小时，打满不会卡住页面）。

版本号改成双行展示：本仓库发布号 + 官方基底版本，一眼能看出包是给哪代官方客户端做的。

## Windows：程序内一键更新

更新页里点一下就把升级包下下来，带进度，装完自动重启。之前只能自己去 Release 页下安装包。

同时改了默认行为：隐藏任务栏图标，只留托盘；开机自启托管在控制台里开关，不用自己去「启动」文件夹里翻快捷方式。

## 桌宠右键菜单 / 状态栏入口

- Windows 右键点桌宠弹出菜单：打开控制台、切换外观模式、退出。
- macOS 状态栏菜单加了「控制台」。
- 从托盘/状态栏点开控制台时，现在先叫起面板再发指令——之前会偶发「指令执行了但面板没出来」。

## 跟进上游 FullAtlas 1.3.4 / 1.3.7

- **我的预设**：背包里「我的预设」的预览图按名字落到本机图，不再显示成 `？`。
- **打字自动表情**：输入时按上游规则自动切表情。
- **分类收集进度**：图鉴里能看到按分类的收集进度。
- **403 处理**：裸 403 不再被当成凭证失效把人踢下线，只提示稍后重试。
- **macOS 国际服接入 FullAtlas 控制面板**：之前只有国服能用。

## 官方基线与更新链路

- 官方基底跟到 1.0.4，两平台锁里的安装包哈希必须一致，不一致直接拒绝发版，避免发出「两平台不是同一代」的包。
- 官方发新版会自动尝试编译，编译通过才更新基线，失败才提 PR 等人看。
- 官方包下载增加验签与镜像回退：主源挂了会自动换镜像，校验不过不落盘。

## 修复

- 加载遮罩延迟 300ms 才显形，短请求不再闪一下白屏。
- 活动配置的后台刷新不再挂全屏遮罩。
- 图鉴目录请求失败重试 5 次，覆盖国内 CDN 抖动。
- 升级后键鼠监听失效的问题。
- Mod 表情改用本机取图地址；macOS 之前因为只放行 `http(s)://` 而显示不出 Mod 图，这版给两端加了统一的本机取图路由。
- 控制台底栏版本号统一用本仓库发布号，两端不再一个显示 `1.3.0` 一个显示 `1.2`。
- Windows 宿主进程随主程序退出，不再留后台残影。
- Windows 宿主先读完请求体再响应，避免偶发 RST。

## 已知限制

- 表情受官方表情槽位数量上限约束，Mod 表情多了会被截断。
- 图鉴的稀有度筛选下拉里没有 `MOD` 项，按稀有度筛选时 Mod 条目会被过滤掉。
- 背包里 Mod 条目按类型标签展示，不是独立分组网格（当前设计如此）。
- macOS 包仍是临时签名，重装后可能需要在系统设置里重新勾选一次「输入监控」。

## 安装

- **macOS**：Apple Silicon / macOS 13 及以上。先把 app 拖进「应用程序」再运行。
- **Windows**：下载 `.exe` 安装，装完双击快捷方式即可；已装 1.2.x 的可以在控制台「更新」页一键升级，也可以直接覆盖安装。
