# Release Notes — 1.3.1

本版完善自动点击、更新检查和打字自动表情，两端继续基于官方国服 / 国际服 1.0.4。

## 自动点击

- 可按可用点数自动启停后台点击。开启后，余额低于 10,000 时自动点击，高于 40,000 时停止，中间区间保持当前状态。
- 两个阈值可在控制台设置，必须保持下限小于上限。此功能开关默认关闭，避免升级后意外开始点击。

## 更新与输入

- 更新检查有超时提示，不会无限停留在检查状态；网络请求超时后可重试。
- 打字自动表情的连续触发间隔调整为约 1.2–2.4 秒。
- macOS 文本焦点识别同时检查系统的可编辑属性，改善部分输入框未被识别的情况。

## 基线

- 国服与国际服的官方最新版本检查均确认仍为 1.0.4，锁定的官方安装地址和摘要未变化。
